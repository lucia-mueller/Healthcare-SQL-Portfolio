# Healthcare SQL Portfolio

This portfolio showcases SQL projects focused on healthcare data analysis, operational reporting, and performance measurement. The projects use fictional datasets to demonstrate practical SQL skills and analytical approaches applicable to healthcare operations and value-based care.

## Projects

### Provider Productivity Dashboard

Analyzes fictional provider and patient visit data to evaluate provider productivity, appointment volume, and visit completion rates.

**Key analyses include:**
- Total visits by provider
- Average visits per provider
- Identification of providers with no recorded visits
- Monthly appointment volume trends
- Provider-level visit completion rates

**SQL techniques demonstrated:**
- LEFT JOIN
- GROUP BY
- Aggregate functions (`COUNT`, `SUM`)
- `CASE` statements
- Date functions
- `NULLIF`
- Percentage calculations
